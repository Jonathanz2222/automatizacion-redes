# Paso 3. Explorar documentación oficial de Python

## 1. ¿Qué es la documentación oficial de un lenguaje de programación?
Es el conjunto de manuales y recursos publicados por los desarrolladores oficiales de un lenguaje de programación. Explica cómo funciona el lenguaje, cuáles son sus instrucciones y cómo utilizarlas correctamente.


## 2. ¿Qué información puede encontrarse en ella?
Se pueden encontrar explicaciones de las instrucciones, ejemplos de código, tutoriales, descripción de funciones, tipos de datos, listas, diccionarios, ciclos, módulos y recomendaciones para utilizar el lenguaje correctamente.


## 3. ¿Cómo puede ayudar a resolver dudas sobre Python?
Permite consultar la sintaxis correcta y ejemplos de uso de cada elemento. Por ejemplo, ayuda a crear variables para guardar direcciones IP, listas para almacenar dispositivos, diccionarios para organizar sus características, ciclos para recorrerlos y funciones para reutilizar instrucciones.


## 4. Diferencia entre la documentación oficial y los foros
La documentación oficial proporciona información elaborada y mantenida por los responsables del lenguaje. En cambio, los foros contienen respuestas de otros usuarios que pueden compartir experiencias y soluciones, pero que podrían estar incompletas, desactualizadas o ser incorrectas. Ambos recursos son útiles, aunque es recomendable verificar las soluciones con la documentación oficial.S
